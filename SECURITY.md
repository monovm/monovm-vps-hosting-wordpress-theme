# Security Policy

## Supported versions

Security fixes are provided for the latest released version of MonoVM Blueprint.

| Version | Supported |
|---|---|
| 1.0.x | Yes, after release |
| Unreleased development snapshots | No guarantee |

## Reporting a vulnerability

Do not publish a suspected vulnerability in a public issue or WordPress.org
support topic. Use GitHub's private vulnerability-reporting flow for the
`monovm/monovm-vps-hosting-wordpress-theme` repository. Include:

- affected version;
- reproduction steps;
- expected and actual behavior;
- security impact;
- any suggested mitigation.

The maintainer should acknowledge a complete report within three business days.
Public disclosure should wait until a fix or coordinated mitigation is ready.

## Scope

The theme intentionally contains no telemetry, external updater, custom
endpoint, account system, billing integration, provisioning integration, or
theme-owned data store. Reports about third-party plugins or services should be
sent to their respective maintainers.
